## 🌟 Projects

Here are some highlighted projects (see my GitHub for more):

- **LocalNeural** – The *Ultimate Private AI Interface*. Self-hosted web chat supporting local (Ollama) and cloud models (OpenAI, Gemini, etc) with streaming, RAG, and multimodal vision.  
- **LineSolv** – A **cross-platform natural-language calculator**. Understands phrases like “$20 in euro - 5% discount” and combines a Go-based math engine with a clean UI.  
- **AxiomPy** – A **Python math engine** built from first principles. Provides linear algebra, graphs, number theory, autodiff, optimization, signal processing, and more through a single API.  
- **neocut** – CLI tool to **remove silence from MP3s**. Auto-detects, splits and recombines audio to trim silence.  
- **neorwc-cli** – “Neo Read Write Create”: an AI-powered CLI that scans your codebase and auto-generates project documentation using multiple LLM providers.
